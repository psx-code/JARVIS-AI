# 🤖 JARVIS — Personal AI HUD Assistant
### The Futuristic Cross‑Platform AI Companion — By Poorna

A real‑time AI interface inspired by Iron Man’s JARVIS. It listens, thinks, speaks, and automates tasks — with a cinematic HUD design and deep system integration.

---

## ✨ Overview
JARVIS is a next‑generation personal AI assistant that merges **voice interaction, system monitoring, automation, and a futuristic HUD interface**.  
It is engineered to feel alive — responding dynamically to your commands, adapting its visuals, and extending your digital presence with smart automation.  
Unlike traditional assistants, JARVIS combines **visual immersion** with **functional intelligence**, making it both practical and cinematic.

---

## 🚀 Capabilities

### 🎙️ Voice Interaction
- Real‑time microphone input with circular waveform visualization  
- Adaptive color states:  
  - **Blue** → Listening  
  - **Amber** → Thinking  
  - **Green** → Speaking  
  - **Red** → Muted  

### 🖥️ System Monitoring
- CPU, Memory, and GPU usage displayed as dynamic circular gauges  
- Uptime, process count, and network activity tracking  
- Telemetry ticker at the footer for live system stats  

### 🔷 Futuristic HUD
- Central **arc reactor core** with pulsing energy rings  
- Dual rotating rings (audio waveform + system load arcs)  
- Animated hexagonal grid background with holographic scan line sweep  
- Particle streams radiating outward when speaking  

### 📂 File & Command Handling
- Drag‑and‑drop file upload panel (images, video, audio, docs, code, data)  
- Command input box for direct queries and instructions  
- Activity log with frosted glass effect and glowing notification badges  

### 🌐 Network Visualization
- Animated topology line in the header  
- Mini‑map showing active tools and AI core status  

### 📱 Smart Away Mode
- Detects when the user is unavailable  
- **Manual activation toggle** to enable Away Mode on demand  
- Automatically sends polite auto‑replies to WhatsApp messages  
- Keeps a log of missed messages for later review  

### 🧩 Notifications
- Real‑time activity log updates  
- Red notification badges when new events occur while scrolled up

## 🔑 Configuration Loader

JARVIS uses a JSON file (`api_keys.json`) to store API keys and OS settings.  
This makes the system portable across Windows, macOS, and Linux.

```json
{
  "gemini_api_key": "your_key_here",

}
